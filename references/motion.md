# 可复用动画合成方法

## 可选片头：从一个实验展开素材网格

- 先让观众看清一个清晰的实验片段，随后把它缩小成为网格内的一个确定单元。单元身份及播放时间连续，不在缩小途中突然换素材。
- 网格使用多任务、多场景的真实数据和生成结果，不必全部是生成视频；来源记录在工程中，屏幕标签只保留观众理解所需。
- 想要密集感可增加行列数，但保持有关联的视角相邻，并按实验定义同步。边缘细线、统一裁剪和错开的取景时间能避免杂乱。
- 一个可调整节奏：全屏片段约 2 秒，缩小/铺开约 2–3 秒；白色半透明面板先出现，约 0.4 秒后艺术字进入，再出现完整论文题目。完整标题需有足够阅读停留。
- 标题面板用真实 alpha 合成，下面视频继续运动。艺术字优先使用提供的透明素材，不用重生成的近似字。
- 清理额外叠加的说明标签和装饰水印，不静默抹除第三方应保留的署名。不要把与论文内容无关的操作说明显示给观众。

## 主图运镜：单一底图 + 连续蒙版

使用完整原图作为固定源，给每一讲解状态定义：

```text
source_roi = (left, top, right, bottom)  # 原图像素或明确的归一化坐标
viewport = (left, top, right, bottom)    # 视频画布坐标
heading, optional_callouts, start_frame, duration_frames
```

统一 source 坐标单位，不能混用截图尺寸与原图尺寸。将 source ROI 按等比例 `contain` 放进 viewport：

```text
scale = min(viewport_width / roi_width, viewport_height / roi_height)
image_tx = viewport_left + (viewport_width - roi_width * scale) / 2 - roi_left * scale
image_ty = viewport_top  + (viewport_height - roi_height * scale) / 2 - roi_top * scale
```

通过相邻关键帧插值源图的 scale/translation，以及 viewport 的位置/大小；每帧用当前 viewport 裁剪完整源图。缩放可在 log(scale) 空间插值，平移和框边界用线性插值加 easing。

- `u = clamp(t / transition_duration, 0, 1)`，可用 `6u^5 - 15u^4 + 10u^3` 获得平滑启停。
- 相邻页共享上一页结束状态。约 1.0–1.5 秒转换可作为起点，按讲解节奏调整。
- 框外区域隐藏，圆角和细描边随框变化；标题与辅助文字在运镜中淡出/淡入，而非跟着图像缩放。
- 先总览整张主图，再按论文的输入、处理模块和输出等逻辑块讲解。
- 局部模块的取景应包含理解它所需的输入、输出和连接；不要截断输出图片来给冗长文案让位。
- 更改状态 B 后，除了 A→B，还要重渲染 B→C。零时刻、25%、50%、75%、结束都应查看，并播放过渡片段确认连续性。

局部图解需要动起来时，在上述连续取景之内插入动画图层。原图到动画的交叉淡入和主图之间的平移缩放是两种不同转换；实现与检查见 [科研图解动画](diagram-animation.md)。

## 结果：增长、排序、Top-K 淘汰

保留原始 metric、方向、模型、数值和精度。每个指标独立排序；误差指标升序，质量指标降序。同一方法的不同变体在各指标中的次序按真实数值决定。真实并列保持稳定顺序，不暗示不存在的显著差异。

一个容易读的节奏：对照方法先出现，条长从零增长；本方法加入并上移到其真实最终名次。显示 Top-K，落出 K 名的行继续向下进入 viewport 外，不在中间突然消失。用统一坐标空间同步移动名称、条形和数值。

- 条长保持零起点的线性原始数值尺度，低为优的指标中赢家自然可能更短；用 `↓` 解释方向，不把数值反转伪装成更长。
- 比较范围使用方法真实名称，不用 `best baseline` 替代。旁白不必逐个读对照模型。
- 同一指标同一时刻共用尺度。若为处理极大离群值使用动态尺度，所有条一起转换并显示当前刻度；优先固定尺度。
- 柱上数值显示最终真实值，条长完成入场动画后停稳。增长仅是视觉进入效果，不代表训练过程中观测到的时间序列。
- 默认不滚动数字。若用户单独要求数字动画，应与柱上稳定数值分开处理，不把早期尝试保留为最终默认。
- 多指标页面 2×3 卡片是可选布局；单指标页面可按可读性展示更多条目。用完整指标名，不依赖观众记缩写。

### 可选的群组连续遮挡

若多个相邻条目作为一个群组移动，且选择遮挡式过渡，让被覆盖内容在整个群组经过期间连续隐藏，避免间隙闪现。

实现一个连续的群组遮挡区域，纵向覆盖所有成员的最上缘到最下缘，包括中间间隙；不要对每行单独求透明度再叠加。

```text
group_top = min(row.top for row in moving_group)
group_bottom = max(row.bottom for row in moving_group)
covered = baseline_bottom >= group_top and baseline_top <= group_bottom
```

对边缘留出文字 ascent/descent 的余量。其他行使用这一整块决定可见性；靠近边缘可以短暂淡入淡出。若使用弹簧或多段交换导致坐标回摆，应对一次通过过程锁存 hidden 状态，直到该群组整体越过，防止闪烁。移动群组画在上层；遮挡只作用于需要避让的图表内容，不隐藏字幕或外部标题。

检查：在每个被超越的 baseline 上逐帧观察，不能在群组成员先后经过之间露出名字；最终所有仍在 Top-K 内的方法完整恢复。
