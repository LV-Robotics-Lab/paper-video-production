# 科研图解动画

用于将扁平论文图、PPT 结构图或流程图变成可解释的动画，同时接续已有运镜与旁白。这里的参数是制作起点，按用户参考、页面密度和实际语速调整。

## 先识别参考动画在解释什么

用户给参考视频时，先播放相关段落，结合前、中、后关键帧判断：是镜头在移动，还是节点、箭头、token、纹理在运动；哪些结构一直保持稳定；高亮如何对应旁白。不要只看封面就照搬风格。

逐项把“论文机制 → 可见元素 → 动作 → 旁白时间”对应起来。信息传递可沿箭头移动，处理可用局部脉冲，几何关系可用相机与射线变化；每个动作应有解释对象。优先保持布局稳定，让注意力集中在当前被讲解的路径上。

## 素材与重画策略

- 先检查 PPT、SVG、PDF 或原工程是否有独立形状和高分辨率素材；用户说截图不可拆分时，也可利用其提供的源文件检查真实可编辑性。
- 只有扁平图时，按论文核对标签、节点、连接方向、分组、坐标系与公式，再重画成原生图层。PIL、SVG、Canvas 或现有视频框架均可；无需为了动画更换整套工程。
- 规则形状、文字、箭头、坐标轴和 token 适合确定性绘制。相机或立方体等简单示意图标也可原生重画，便于旋转、移动及重新连接射线。
- 确实需要复杂插画或纹理素材，且 imagegen skill 可用时，按其说明生成独立素材；优先请求无字、无箭头、独立对象与真实透明背景，合成时再加准确标签和连接。用户指定模型时检查工具是否支持选择，不能声称使用了不可选择的模型。
- 数学噪声、曲线或矩阵可以根据受控参数程序化生成。重画科学图不是重新猜一张相似图片；图中文字与拓扑始终以论文和原图为准。
- PNG 的黑色查看背景可能代表透明区域。先检查 alpha，在目标背景上看边缘，不按全图颜色阈值删除黑白像素；照片、标志中的白色不一定是待移除背景。

建议将原图底层、节点/照片、固定标签、连线、运动标记、强调层、标题和字幕独立组织。动画函数接收场景局部时间，随机示意素材使用固定种子，保证单帧重渲染与完整导出一致。轮廓与文字可用较高分辨率绘制后降采样，避免细箭头闪烁。

## 原图运镜 → 动画讲解 → 返回原图

延续已有方法总览时，复用完整主图、source ROI、viewport 与取景状态，坐标计算见 [动画合成](motion.md)。

1. 从上一状态连续平移、缩放到本区域，取景框与底图同时变化。
2. 到位后短暂停留，在相同 viewport 内将原图交叉淡入动画版。尽量保持节点相对位置、语义颜色和阅读顺序，减少重认结构的负担。
3. 动画按照旁白顺序强调路径。框、标题和字幕保持独立，避免整页交叉淡入造成两套字幕重影。
4. 讲解结束前淡回**同一主图、同一 ROI、同一相机和蒙版状态**，随后继续下一段平移缩放。

一个已有成片可用的时间模板：先运镜 1.4 秒，停稳 0.2 秒，再用 0.65 秒淡入动画；结束前 1.0 秒开始用 0.65 秒淡回原图，留约 0.35 秒供下一段接续。短页可缩减这些时间，不因固定模板压缩语句或切掉词尾。

```python
# t 为场景局部秒数；所有区间必须适合当前场景时长。
def smoothstep5(u):
    u = min(1.0, max(0.0, u))
    return u**3 * (u * (6*u - 15) + 10)

alpha = smoothstep5((t - enter_start) / enter_duration)
alpha *= 1 - smoothstep5((t - exit_start) / exit_duration)
# 原图和动画先在相同 viewport、相同背景上合成，再 blend；
# 标题和单行字幕在最上层单独绘制。
```

交叉淡入须合成真实背景，避免透明区域带黑边。若改动后的入口与出口状态仍与旧版完全一致，后续运镜可直接复用；若改变 ROI、框位置或时长，则重渲染受影响的相邻场景。

## 常用机制的动画表达

| 解释对象 | 可复用做法 | 需要守住的含义 |
| --- | --- | --- |
| 信息流 / 编码流程 | 在固定箭头上放移动光点，节点在接收时轻微亮起 | 光点沿折线累计弧长匀速移动，不在拐角跳跃或每段重置；方向与真实依赖一致 |
| 中心节点 / 多分支交换 | 局部自循环与经中心节点的双向流；节点内 token 按序脉冲 | 两个方向用分开的路径；论文没有直接全连接时，不新增直连边 |
| 分离编码 / rotary bands | 独立颜色带、小相位指针、标签到对应频带的短流动 | 不把角色和视角编码混在同一带；保持身份间的相对相位关系，说明仅为机制示意 |
| 相关噪声 / 几何变换 | 相机沿轨迹轻移；共享基础噪声经连续变换形成相关噪声栈 | 若论文还包含独立噪声混合和方差归一化，示意也要反映；独立随机刷新不能冒充相关噪声 |
| 相机射线 / 条件分支 | 相机、视锥和射线同步更新；两条特征路径各自流向目标 | 相机运动后更新所有附属坐标；射线、pose、attention bias 的目标不互换 |
| 同步与预处理 | 分散的采样点逐渐对齐时间网格；处理模块依次高亮 | 对齐频率、模态和单位取自论文；示意点不伪装成实际采集轨迹 |
| 质量检查 | 检查项按旁白先后出现勾选，再进入 train-ready 节点 | 表示流程步骤，不能凭动画声称真实数据已通过验证 |
| 数据金字塔 | 照片在分层多边形蒙版内，各层随叙述高亮 | 来源标签、量级、字号保持一致；素材按纵横比排版，宽标志可独立成行 |

持续运动宜小而明确：移动点、局部描边、顺序高亮通常比整图反复缩放更适合机制讲解。同屏有多个模块时，按旁白提升当前模块亮度，其余降低强调但保持可读；不要所有分支同时快速闪动。

示意动画与实验数据要分清。粒子不是测得的注意力，噪声演示不是生成视频，示意相机轨迹不是机器人执行轨迹。将这一属性记在工程依据中；当画面本身容易被误认成实验结果时，用简洁标注澄清，不默认给每页加大段说明。

## 接续、验证与交付

- 用现有 timeline 的整数帧数与字幕 cues；不要从旧版本脚本带回已改掉的字幕、起始时间或混音。最好将通用渲染函数与执行入口分开，避免导入模块就渲染全片。
- 只改视觉时保持场景时长，完整成片直接复用已确认的音轨；需要精确切出的短预览可以重编码音频。验证完整成片的音频包或解码音频哈希，不能以 MP4 容器哈希判断声音是否改变。
- 先看完整动画画面，检查字号、布局、遮挡、箭头连接、照片裁剪与字幕安全区，再播放含前后相邻场景的短片。只给孤立动画无法判断运镜衔接。
- 抽查进场、淡入中间、动画中段、淡出中间、返回原图和下一段开始。原始帧可做像素对比，确认入口/出口一致；编码后的画面用视觉或容差对比，不要求有损编码逐像素相同。
- 实际播放检查光点速度、噪声连续性、细线闪烁、转场跳变和字幕可读性；运行 ffprobe 与全片解码检查。只有播放器在播而没有听到音频时，不声称已试听。
- 在用户授权的当前工作范围内先制作可审阅片段；若当前任务包含整片更新，检查通过后继续拼接，不把局部预览当作最终完成。只有用户要求阶段确认时才等待确认。
- 交付清晰命名的方法段预览和需要更新的完整视频；保留上一版本。脚本与小型参数留在项目中，大型媒体不要复制到 skill。
